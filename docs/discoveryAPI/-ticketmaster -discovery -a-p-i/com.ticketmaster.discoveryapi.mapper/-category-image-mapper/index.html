class CategoryImageMapper

Maps URLs to category identifiers for the Ticketmaster Discovery API.

This class provides methods to determine the appropriate category identifier based on URL patterns, supporting categories such as comedy, concerts, arts and theater, family, festivals, sports, and miscellaneous.
