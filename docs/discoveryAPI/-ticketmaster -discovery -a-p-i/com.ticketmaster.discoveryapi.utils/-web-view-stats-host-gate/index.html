WebViewStatsHostGate

object WebViewStatsHostGate

First-party gate for the WebView /stats timing telemetry (MA-13896).

The Retail SDK exposes its /stats reporter through public, mutable SDK properties (PrePurchaseSDK.webViewStatsReporter / TMPurchaseSDK.webViewStatsReporter), so on its own any third-party integrator could assign a reporter and start POSTing timing payloads to mobs.ticketmaster.com/stats. iOS prevents this with a private "stealth communicator" handshake; this gate is the Android analog — the reporter is only honored when the SDK is embedded in a genuine Ticketmaster host application.

The check is intentionally broader than com.ticketmaster.discoveryapi callers' isTMPackage helper: it also admits the beta package, because the feature is exercised and shipped on the Home & Explore beta build, not only on production.
