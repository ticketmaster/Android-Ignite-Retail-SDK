StatsEventNames

object StatsEventNames

Canonical /stats event_name values (MA-13896) — the single source of truth for the telemetry contract. Every emit site and the reporter allow-list reference these constants so a typo becomes a compile error rather than a silently-dropped event (an unknown name fails WebViewStatsReporter's allow-list check and only bumps the bridge_unknown_event counter).

Names are shared with the iOS client and the backend; do not change a value without updating both. ALLOW_LIST is the set the reporter validates against.
