class WebViewStatsReporter

System of record for webview timing. Holds per-instance t0 (native monotonic clock), validates event names, computes native-from-native and page-from-page deltas, enqueues to the ring buffer, and flushes fire-and-forget.

WebViewStatsReporterFactory
Link copied to clipboard
object WebViewStatsReporterFactory

Builds a production WebViewStatsReporter: an OkHttp-backed transport (the SDK-standard HTTP client), native monotonic clock, and a 30 s flush scheduler bound to scope. The host supplies enabled (default-off feature gate) and a contextProvider for session/app/device fields (keeps foundation dependency-clean — no reach-up).

WebViewTimingIife
Link copied to clipboard
object WebViewTimingIife

The self-measuring IIFE injected at document-start. Reads Navigation Timing, observes LCP (preferring a tm-rendered mark when web provides one), and posts ONE report to the native bridge. Wrapped, no globals, all try/catch, never throws into the page. A 28s self-timeout emits bridge_no_render if render never fires (slightly under the native 30s lost_timing window so a report wins over a drop).
