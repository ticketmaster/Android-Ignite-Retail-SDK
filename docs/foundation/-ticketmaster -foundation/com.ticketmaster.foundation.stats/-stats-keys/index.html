StatsKeys

object StatsKeys

Canonical JSON field names for the /stats telemetry contract (MA-13896) — the single source of truth shared by the producer (StatsEvent.toJsonMap) and every consumer (the IIFE payload readers in the pre-purchase / retail WebViewTimingBridges and SearchStatsTapIn).

Two overlapping groups:

  • the outbound /stats event body (everything below), and

  • the inbound IIFE report payload, which is the subset the injected script emits (REQUEST_MS, RENDER_MS, RESPONSE_SIZE_BYTES, PAGE_ELAPSED_MS, BRIDGE_NO_RENDER, RENDER_SOURCE).

Keeping these in one place makes a producer/consumer key mismatch a compile-time reference rather than a silently-dropped field. Shared with the iOS client and the backend — do not change a value without updating both.
